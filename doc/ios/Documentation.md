In this documentation folder, you can find the source code of the 3 classes of the Meta Wearables DAT:
- `MWDATCore.swift`
- `MWDATCamera.swift`
- `MWDATMockDevice.swift`

This repository also includes the `CameraAccess` iOS sample (Swift) from Meta. The Flutter `example` app replicates all features of this sample, providing a cross-platform equivalent for plugin users.
To keep the repository lightweight, the iOS sample app is excluded via .gitignore. If needed, you can clone it directly from `https://github.com/facebook/meta-wearables-dat-ios/tree/main/samples/CameraAccess`.
